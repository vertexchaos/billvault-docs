# BillVault documentation (published copy)

This repository is **generated**. It holds only the documentation pages that the owner has approved for
publication, copied from the private BillVault repository by `scripts/build_public_docs.py` after a
secret and personal-data scan. Do not edit it by hand: changes are overwritten on the next publish.

- Build locally: `pip install -r requirements.txt && mkdocs build --strict`
- Read the Docs builds it with `.readthedocs.yaml`.
