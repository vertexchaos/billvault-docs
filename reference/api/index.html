    POST /api/documents/merge¶

    Phase 12.5: one batched query instead of one per requested document id. merge_documents() relies on documents' order matching payload.document_ids exactly (order's (doc_idx, page_number) pairs index positionally into it) -- rebuild that order explicitly since .in_() does not guarantee result order.

    Request body (required): application/json: MergeDocumentsRequest

    Status Meaning Body
    200 Successful Response application/json: DocumentOut
    422 Validation Error application/json: HTTPValidationError

    GET /api/receipts¶

    Phase 12.1: previously unbounded -- returned every matching row in one response. limit/offset keep this from fetching/serializing the entire receipts table on every call.

    Parameter In Required Type Description
    vendor query no string or null
    status query no string or null
    limit query no integer
    offset query no integer

    POST /api/receipts/{receipt_id}/reprocess¶

    Phase 11 (gap #2): retry extraction on an already-ingested receipt (bad OCR, gateway was briefly down, etc.) -- the only prior re-extraction trigger was the page-op routes above, which only ever act on a newly-created derived Document. Mirrors the admin-action trigger in app/admin.py's ReceiptAdmin.reprocess_receipts, same pattern as this file's own _enqueue_page_op_reextraction.

    Parameter In Required Type Description
    receipt_id path yes string:uuid
    Status Meaning Body
    200 Successful Response application/json: ImportBatchOut
    422 Validation Error application/json: HTTPValidationError

    DocumentOut¶

    Phase 10: response schema for page-op routes -- not the full receipt/extraction detail (ReceiptDetailOut covers that once re-extraction finishes), just enough to confirm what was created and its lineage.

    original_filename string yes Original Filename
    status DocumentStatus yes
    file_hash string yes File Hash
    derived_from_id string:uuid or null yes Derived From Id
    edit_reason DocumentEditReason or null yes
    created_at string:date-time yes Created At
